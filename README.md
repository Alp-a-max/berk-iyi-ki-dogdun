# İyi ki doğdun, Berk!

Fotoğraf gerektirmeyen, 3D ve etkileşimli doğum günü sitesi. Krom hediye kutusu, doğum günü pastası, sürpriz düğmesi ve dilek makinesi içerir.

Yayın adresi: https://alp-a-max.github.io/berk-iyi-ki-dogdun/

## Yerel çalıştırma

Dosyaları bir statik HTTP sunucusu üzerinden açın (örneğin VS Code Live Server). ES modülleri nedeniyle index.html dosyasını doğrudan çift tıklamak yerine HTTP kullanın. Derleme ve paket kurulumu gerekmez.

## Dosyalar

- `index.html`: İçerik ve erişilebilir kontroller.
- `style.css`: Duyarlı tasarım.
- `app.js`: Three.js sahneleri, kutlama ve etkileşimler.
- `assets/`: Yerel Three.js ve yazı tipi dosyaları; ilgili lisanslar.

İsim tarayıcıda değiştirilebilir. Varsayılan isim Berk’tir. Ses ziyaretçinin isteğiyle etkinleşir; isim tercihi yalnızca ziyaretçinin tarayıcısında saklanır.

GitHub Pages, `main` dalının kök dizininden yayınlanır. Site tamamen statiktir; API anahtarı veya sunucu gerektirmez.
